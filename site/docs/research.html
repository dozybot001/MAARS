Research研究

Research is a state graph, not an agent loop.Research 是状态图，不是智能体循环。

The Research stage turns a refined idea into verified task outputs. LangGraph owns control flow. Codex owns each concrete task execution.Research 阶段把精炼后的想法转成经过验证的任务输出。LangGraph 负责控制流，Codex 负责每个具体任务的执行。

Research graph研究图

The high-level graph is stable and inspectable. Each node is implemented on ResearchStage and exposed through ResearchStageGraphNodes.高层图稳定且可检查。每个节点由 ResearchStage 方法实现，并通过 ResearchStageGraphNodes 暴露。

calibrate
  -> initialize_loop
  -> prepare_strategy
  -> prepare_decomposition
  -> execute_tasks
  -> evaluate_round
  -> initialize_loop | end

Task cycle任务周期

Each atomic task runs through a smaller graph. Retries stay local, so the full research loop does not become a tangled control-flow function.每个原子任务通过一个更小的图运行。重试保持在任务局部，避免整个研究循环变成纠缠的控制流函数。

execute_attempt
  -> verify_attempt
  -> complete | retry | failed | redecompose

Retries include previous output and reviewer feedback. Codex is asked to address the feedback without redoing correct work.重试会带上前一次输出与审查反馈。Codex 只需要修复反馈指出的问题，不必重做已经正确的部分。

Codex contractCodex 契约

Codex receives a task contract, not a vague prompt. The executor writes a JSON Schema into the workspace and requires the final response to satisfy it.Codex 收到的是任务契约，不是模糊 prompt。执行器会把 JSON Schema 写入工作区，并要求最终响应满足该 schema。

Field字段Meaning含义
markdownComplete task result, commands, outputs, and artifact references.完整任务结果、命令、输出与产物引用。
summaryOne concise line with filenames and key numeric results.一行摘要，包含文件名与关键数值结果。
artifactsDurable files written under ./artifacts/.写入 ./artifacts/ 的持久文件。
warningsExplicit blockers or caveats. Empty when there are none.明确阻塞或注意事项；没有时为空。

Verification验证

Verification happens after Codex returns. The reviewer checks artifacts, command evidence, and whether the deliverable matches the task description.验证发生在 Codex 返回之后。审查器检查产物、命令证据，以及交付物是否匹配任务描述。

Iteration迭代

After a round completes, the evaluator inspects outputs and artifacts. A new strategy round is created only for a specific critical gap.一轮完成后，评估器检查输出与产物。只有存在具体关键缺口时，才创建新的策略轮次。

The runtime is biased toward finishing with honest limitations instead of expanding scope indefinitely.运行时倾向于带着诚实边界完成，而不是无限扩张范围。
Research tasks are independent Codex sessions coordinated by LangGraph.研究任务是由 LangGraph 协调的独立 Codex 会话。
