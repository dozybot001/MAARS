Architecture架构

Runtime first, Codex powered.运行时优先，由 Codex 驱动。

MAARS is now a deterministic research runtime that delegates atomic execution to Codex while keeping orchestration, verification, persistence, and recovery inside the application.MAARS 现在是确定性的研究运行时：原子执行交给 Codex，编排、验证、持久化与恢复仍由应用负责。

Overview概览

The core rule is simple: Python owns workflow, Codex owns task work, files own handoff. Refine and Write handle open-ended prose. Research uses LangGraph for state flow and Codex for concrete task execution.核心规则很简单：Python 负责流程，Codex 负责任务，文件负责交接。 Refine 与 Write 处理开放式文本工作，Research 使用 LangGraph 管理状态流，并用 Codex 执行具体任务。

Docker is no longer a task tool. When enabled, Docker only wraps the same Codex command inside a configured container.Docker 不再是任务工具。启用时，它只是在配置好的容器里包装同一条 Codex 命令。

Contracts契约

Each task receives a TaskContext and returns a TaskExecutionResult. The runtime can change graph routing without changing Codex prompts, and Codex can execute work without knowing research-loop policy.每个任务接收 TaskContext，返回 TaskExecutionResult。运行时可以调整图路由而不影响 Codex prompt；Codex 可以执行任务而无需理解研究循环策略。

ResearchStage
  -> LangGraphResearchRuntime
  -> LangGraphTaskRuntime
  -> CodexExecutor
  -> CodexSandboxProvider
  -> workspace + artifacts + RuntimeEvent

Storage存储

A run is represented by one session directory. Task workspaces are separate from durable artifacts, so Codex can work freely while MAARS preserves stable outputs for later stages.一次运行对应一个 session 目录。任务工作区与持久产物分离，Codex 可以自由工作，而 MAARS 为后续阶段保留稳定输出。

results/<session>/
  refined_idea.md
  plan_tree.json
  workspaces/<task_id>/
  artifacts/<task_id>/
  results_summary.json
  paper.md

Code map代码地图

  • backend/core/research.py defines runtime state and result dataclasses.定义运行时状态与结果数据结构。
  • backend/runtime/ contains the LangGraph research and task graphs.包含 LangGraph 研究图与任务图。
  • backend/executors/codex.py builds the Codex command, parses events, and syncs artifacts.构建 Codex 命令、解析事件并同步产物。
  • backend/sandbox/codex.py provides local and Docker command substrates.提供本地与 Docker 命令基底。
