Refine and Write

Open-ended prose stages stay separate from execution.

Refine and Write are still agentic stages, but they do not execute experiments. They shape research intent and synthesize verified outputs from the Research runtime.

Refine

Refine turns a vague idea into an actionable research objective. The Explorer searches and drafts a proposal. The Critic checks novelty, feasibility, clarity, and scope. The stage loops until no material issues remain or the configured delegation limit is reached.

The output is refined_idea.md. Research treats this file as the starting objective, not as a chat transcript.

Write

Write consumes the deterministic research summary, task outputs, and artifacts. The Writer drafts a paper. The Reviewer checks structure, completeness, figure references, and especially numeric accuracy against raw artifact files.

The stage is deliberately strict: if a number cannot be found in an artifact, the paper must mark it unavailable or remove the claim.

Polish

Polish is a single-pass editorial stage. It may improve structure, flow, and prose, but it must not change numbers, conclusions, metrics, or artifact paths. The system appends deterministic runtime metadata separately.

Fact anchor

The write prompt starts from results_summary.json. That JSON is the canonical factual anchor for the paper. It contains the research goal, task summaries, artifact list, score information, and evaluation status.

Research outputs
  -> results_summary.json
  -> Write draft
  -> Reviewer fact check
  -> paper.md
  -> Polish pass
  -> paper_polished.md
Refine and Write shape meaning. Research produces verified evidence.
