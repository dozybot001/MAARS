Refine and Write构思与写作

Open-ended prose stages stay separate from execution.开放式文本阶段与执行阶段保持分离。

Refine and Write shape research intent and synthesize verified outputs. They do not run experiments directly.Refine 与 Write 负责塑造研究意图、综合已验证输出；它们不直接运行实验。

Refine构思精炼

Refine turns a vague idea into an actionable objective. The Explorer searches and drafts a proposal. The Critic checks novelty, feasibility, clarity, and scope.Refine 把模糊想法变成可执行目标。Explorer 搜索并起草方案，Critic 检查新颖性、可行性、清晰度与范围。

The output is refined_idea.md. Research treats it as the starting objective, not as a chat transcript.输出是 refined_idea.md。Research 把它作为起始目标，而不是聊天记录。

Write写作

Write consumes the deterministic research summary, task outputs, and artifacts. The Reviewer checks structure, completeness, figure references, and numeric accuracy against raw files.Write 消费确定性的研究摘要、任务输出与产物。Reviewer 对照原始文件检查结构、完整性、图表引用与数值准确性。

If a number cannot be found in an artifact, the paper must mark it unavailable or remove the claim.如果某个数值无法在产物中找到，论文必须标记为不可用或删除该断言。

Polish润色

Polish may improve structure, flow, and prose, but it must not change numbers, conclusions, metrics, or artifact paths.Polish 可以改进结构、流畅度与表达，但不能更改数值、结论、指标或产物路径。

Fact anchor事实锚点

results_summary.json is the canonical factual input for the paper. It contains goal, task summaries, artifact list, score information, and evaluation status.results_summary.json 是论文的规范事实输入，包含目标、任务摘要、产物列表、分数信息与评估状态。

Research outputs
  -> results_summary.json
  -> Write draft
  -> Reviewer fact check
  -> paper.md
  -> Polish pass
Refine and Write shape meaning. Research produces verified evidence.Refine 与 Write 塑造意义，Research 产生已验证证据。
