Architecture

Runtime first, Codex powered.

MAARS is now a deterministic research runtime that delegates atomic execution to Codex. This removes the duplicate execution layer while keeping orchestration, verification, persistence, and recovery inside the application.

Overview

The core rule is simple: Python owns the workflow, Codex owns the task work, files own the handoff. Refine and Write still use model agents for open-ended prose work. Research now uses LangGraph for state flow and Codex for concrete task execution.

Docker is no longer a task tool. When enabled, Docker is only a sandbox provider that wraps the same Codex command inside a configured container.

Contracts

Every atomic task receives a TaskContext: session id, task id, description, workspace path, artifact path, dependencies, summaries, prior attempt, and metadata. The executor returns a TaskExecutionResult: markdown, summary, artifacts, best score, events, and raw Codex output.

ResearchStage
  -> LangGraphResearchRuntime
  -> LangGraphTaskRuntime
  -> CodexExecutor
  -> CodexSandboxProvider
  -> workspace + artifacts + RuntimeEvent

The contract is intentionally small. LangGraph does not know about shell commands. Codex does not know about research-loop routing. The DB does not know which sandbox provider was used.

Storage

A run is represented by one session directory. Research task workspaces are separate from durable task artifacts, so Codex can freely work inside a task directory while MAARS keeps stable outputs for later stages.

results/<session>/
  refined_idea.md

Code map

  • backend/core/research.py defines runtime state and result dataclasses.
  • backend/runtime/langgraph_research.py defines the research round graph.
  • backend/runtime/langgraph_task.py defines execution, verification, retry, and failure transitions.
  • backend/pipeline/research_graph_nodes.py and task_cycle_nodes.py adapt existing stage methods to LangGraph nodes.
  • backend/executors/codex.py builds the Codex command, parses JSONL events, validates final payloads, and syncs artifacts.
  • backend/sandbox/codex.py provides local and Docker command substrates.
MAARS docs reflect the LangGraph + Codex runtime architecture.
