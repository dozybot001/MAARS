Research

Research is a state graph, not an agent loop.

The Research stage turns a refined idea into verified task outputs. LangGraph owns the control flow. Codex owns each concrete task execution.

Research graph

The high-level graph is stable and inspectable. Each node is implemented as a method on ResearchStage and exposed through ResearchStageGraphNodes.

calibrate
  -> initialize_loop
  -> prepare_strategy
  -> prepare_decomposition
  -> execute_tasks
  -> evaluate_round
  -> initialize_loop | end

Conditional edges decide whether the loop is complete, another round is needed, or the stage failed.

Task cycle

Each atomic task runs through a smaller graph. This keeps retries local and prevents the full research loop from becoming a tangled control-flow function.

execute_attempt
  -> verify_attempt
  -> complete | retry | failed | redecompose

Retries include the previous result and reviewer feedback in task metadata. Codex is asked to address the feedback without redoing correct work.

Codex contract

Codex receives a task contract, not a vague prompt. The executor writes a JSON Schema into the task workspace and requires the final response to satisfy it.

FieldMeaning
markdownComplete task result, commands run, outputs, and artifact references.
summaryOne concise line with filenames and key numeric results.
artifactsDurable files written under ./artifacts/.
best_scoreOptional structured metric for score tracking.
warningsExplicit blockers or caveats. Empty when there are none.

Verification

Verification is handled by the Research stage after Codex returns. The reviewer checks whether the result contains concrete artifacts, real command output, and deliverables that match the task description.

Small issues trigger a retry. Scope problems or fundamentally wrong decomposition can trigger redecomposition. Passing tasks are saved and become dependencies for later tasks.

Iteration

After a round completes, the evaluator inspects task outputs and artifacts. The default behavior is to stop when the current evidence is sufficient. A new strategy round is created only for a specific, critical gap.

The runtime is biased toward finishing with honest limitations instead of expanding scope indefinitely.
Research tasks are independent Codex sessions coordinated by LangGraph.
